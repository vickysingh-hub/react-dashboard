# React Admin Dashboard

A modern and responsive admin dashboard built using **React 19**, **Tailwind CSS**, **Framer Motion**, and **Recharts**, powered by **Vite** for a fast and optimized dev experience.

## 🚀 Features
- Monthly Sales Overview Chart (Jan–Dec)
- Dynamic month selection with smooth chart updates
- Responsive UI with modern design
- Smooth animations with Framer Motion
- React Router for client-side routing

## 🛠️ Tech Stack
- React 19
- Vite 6
- Tailwind CSS
- Framer Motion
- Recharts
- React Router DOM

## 📦 Install & Run

```bash
npm install
npm run dev
